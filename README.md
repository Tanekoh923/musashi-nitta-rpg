# まちの おつかい冒険

武蔵新田・矢口渡を舞台にした、6歳から遊べるおつかいRPGです。ゴールはアスク下丸子保育園。

## 遊び方

`index.html` をブラウザで開き、「ぼうけんに しゅっぱつ！」を押してください。

- 矢印キー / WASD / 画面の方向ボタン：歩く
- 地面をクリック・タップ：そこまで歩く
- スペース：近くのお店に入る・人と話す
- Shift：はやあるき
- J / 「ぴょん！」：ジャンプ
- おつかいリスト / 「みちの ヒント」：道を表示

りんご・パン・牛乳を集め、保育園に届けるとクリア。星集め、こねこのお手伝い、花集め、シャボンだま遊びも楽しめます。オリジナルBGM付き。

## 顔写真・保存

タイトル画面の「しゃしん」で主人公の顔を設定できます。顔の位置と大きさを調整できます。写真は小さなJPEGに加工し、進み具合とともにプレイヤーのブラウザ内に保存します。写真をサーバーに送信する機能はありません。

保存が制限されたブラウザやプライベートブラウズでは、保存が使えない場合があります。

## 舞台について

実在のお店の名前を使った架空のゲームです。建物・道順・登場人物・商品・コイン価格はゲーム用の創作です。実際の道案内には使えません。店舗・保育園との提携はありません。

- [マルエツ 新田店（公式）](https://www.maruetsu.co.jp/store/9433/)
- [リヨン モアール（大田区商店街連合会）](https://otakushoren.com/trip/1457)
- [オーケー 矢口店（公式）](https://ok-corporation.jp/shop/yaguchi.html)
- [アスク下丸子保育園（大田区）](https://www.city.ota.tokyo.jp/shisetsu/hoikuen/shiritsu/ask-shimomaruko.html)

## GitHub Pages

リポジトリの Settings → Pages で、Source を **Deploy from a branch**、Branch を **main**、フォルダーを **/(root)** に設定すると、ゲームを公開できます。

ゲーム本体はHTMLひとつにまとまっています。インストールやビルドは不要です。
